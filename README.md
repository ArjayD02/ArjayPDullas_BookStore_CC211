AD'S BOOKSTORE WEBSITE
======================

PROJECT CONTENTS
----------------
index.html       Main website page
styles.css       Custom styling and responsive layout
script.js        Shopping cart and contact form front-end behavior
assets/          Images used by the website

HOW TO OPEN THE WEBSITE
-----------------------
1. Extract the downloaded ZIP file to a folder on your computer.
2. Open the extracted ads_bookstore folder.
3. Double-click index.html.
4. The website will open in your default web browser.

RECOMMENDED EDITOR
------------------
You can edit the project files with Visual Studio Code or another text editor.
Keep the assets folder in the same project folder as index.html so the images
continue to load correctly.

CUSTOMIZING THE WEBSITE
-----------------------
- Edit index.html to change text, book titles, prices, contact details, or page
  content.
- Edit styles.css to change colors, spacing, fonts, and layout.
- Edit script.js to change shopping cart behavior and other interactions.
- Replace images in the assets folder with your own images. Keep the existing
  filenames, or update the corresponding image paths in index.html.

FEATURES
--------
- Responsive bookstore layout using Bootstrap 5.
- Home, About Us, Books, Shopping Cart, and Contact Us sections.
- Add-to-cart functionality with quantity and total calculations.
- Contact form interface.

IMPORTANT NOTES
---------------
- An internet connection is required for Bootstrap resources loaded from the
  CDN.
- The shopping cart runs in the browser and is a front-end demonstration.
- The contact form is a front-end demonstration. To receive messages, connect
  it to an email service or a server-side backend.

Enjoy your AD's Bookstore website!
